# CRONIA - Quick Start Guide

## En 3 Pasos

### 1. Abre Terminal

```bash
cd C:\Users\agrod\developer\proyecto\cronia
npm start
```

### 2. Escanea el QR en Expo Go

- Abre **Expo Go** en tu teléfono
- Presiona **"+"** o **"Scan QR"**
- Apunta a la cámara al QR que aparece en la terminal

### 3. ¡Disfruta!

La app se cargará automáticamente. Puedes:
- ✅ Crear tareas, notas, eventos y hábitos
- ✅ Buscar y filtrar registros
- ✅ Ver estadísticas detalladas
- ✅ Cambiar tema y configuración
- ✅ Exportar datos

---

## Recarga de Código

Si cambias algo en el código:

**En Terminal:** Presiona `r`  
**En Dispositivo:** Shake (iOS) o 2-finger tap (Android) → Reload

---

## Ver Errores

**Problemas con el QR?**
```bash
npm start -- --tunnel
```

**Ver logs en vivo?**
Presiona `j` en la terminal
